Questão 08. Explique detalhadamente o comportamento do programa abaixo quando executado no
console. Apresente qual será a saída exata gerada pelas sequências de escape utilizadas no formato de
controle:


#include <stdio.h>
#include <stdlib.h>
int main()
{
printf("\n\t\"Primeiro programa\"");
system("PAUSE");
return 0;
}

o \n pula uma linda, enquanto o \t dá um espaço de um tab
o \""\ permite que as aspas apareçam no texto sem dar erro 
na compilação. O system("PAUSE") serve para dar uma pausa 
no código esperando um comando para executar o programa.

Saída:

        "Primeiro programa"Pressione qualquer tecla para continuar. . .
